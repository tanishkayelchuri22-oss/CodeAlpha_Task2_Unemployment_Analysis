# CodeAlpha Task 2 - Unemployment Analysis

## Project Overview

This project analyzes unemployment trends in India using Python.

The analysis focuses on unemployment rates, regional differences, urban and rural areas, monthly patterns, labour participation, and changes during the COVID-19 period.

## Dataset

The analysis uses the "Unemployment in India" dataset.

### Main columns

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Data cleaning
- Missing-value handling
- Duplicate checking
- Date conversion
- Descriptive statistics
- Unemployment trend analysis
- COVID-19 period analysis
- Regional analysis
- Urban vs Rural analysis
- Monthly analysis
- Labour participation analysis
- Correlation analysis

## Key Findings

The overall average unemployment rate was 11.79%.

The average unemployment rate was approximately 9.4% in 2019 and approximately 15.0% in 2020.

Before the selected COVID-19 period, the average unemployment rate was 9.51%. During the selected March-June 2020 period, it increased to 17.77%.

The analysis also identified differences in unemployment across regions, areas and months.

## Conclusion

The project demonstrates how Python-based data analysis and visualization can be used to examine unemployment trends and identify patterns in economic data.
